# Data source

The files in `raw/` are the **Brazilian E-Commerce Public Dataset by Olist**.

- Original publication: [Kaggle — olistbr/brazilian-ecommerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- Copy used here: [olist/work-at-olist-data](https://github.com/olist/work-at-olist-data/tree/master/datasets) (public GitHub mirror, no login required)

This is real, anonymised commercial data covering 99,441 orders placed on the Olist store between 2016 and 2018. Re-download with `scripts/download_data.sh` if needed.

Please respect Olist's dataset licence (CC BY-NC-SA 4.0) if you republish the files.
